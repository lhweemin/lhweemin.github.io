# Hwee Min's Portfolio

Personal portfolio site, written by hand in HTML, CSS and JavaScript and hosted on GitHub Pages.

Live site: https://lhweemin.github.io

## Features
- Responsive layout that works on phone and desktop
- Scroll fade-in animations using IntersectionObserver
- Respects the "reduce motion" accessibility setting
- No frameworks or libraries, just three files

## Files
- `index.html` has the content and structure
- `style.css` has the styling and animations
- `script.js` has the scroll reveal

## Run locally
Open `index.html` in a browser. No build step is needed.
