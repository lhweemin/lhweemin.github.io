# Hwee Min's Portfolio

Personal portfolio site, written by hand in HTML, CSS and JavaScript and hosted on GitHub Pages.

Live site: https://lhweemin.github.io

## Features
- Two themes with a toggle button: a clean classic look and a blocky pixel-adventure look
- Remembers the visitor's theme choice between visits
- Responsive layout that works on phone and desktop
- Scroll fade-in animations using IntersectionObserver
- Respects the "reduce motion" accessibility setting
- No frameworks or libraries, just plain files

## Files
- `index.html` has the content and structure
- `style.css` has the classic styling and animations
- `blocky.css` has the toggle button and the blocky theme (only active when the blocky theme is selected)
- `projects.js` has the project data
- `script.js` has the scroll reveal, the theme toggle and the project pop-ups

## Run locally
Open `index.html` in a browser. No build step is needed.
